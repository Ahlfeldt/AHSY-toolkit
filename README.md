# AHSY-toolkit
Toolkit for micro-geographic commercial and residential property price and rent indices

**© Gabriel M. Ahlfeldt, Fan Yin**

Version 0.90, 2026

## General remarks

This toolkit covers the algorithm developed in [Ahlfeldt, Heblich, Seidel, Yin (2026)](https://github.com/Ahlfeldt/DPs/blob/main/GA_SH_TS_FY_-_Productivity.pdf) to generate micro-geographic property price and rent indices for arbitrary spatial units based on transaction data.

The toolkit includes applications to both **commercial** and **residential** property markets. At this point, it contains the indices created by Ahlfeldt, Heblich, Seidel, Yin (2026) for Germany. We keep updating these indices as time goes by. These micro-geographic property price indices are based on **real micro-data** from Scout24. They can be found in the following sub-folder: [APPLICATIONS/DATA/OUTPUT](https://github.com/Ahlfeldt/AHS2023-toolkit/tree/main/APPLICATIONS/DATA/OUTPUT). For replication, the underlying microdata must be accessed from the Forschungsdatenzentrum at RWI-Essen.

Compared to the methodology introduced in [Ahlfeldt, Heblich, Seidel (2023)](https://doi.org/10.1016/j.regsciurbeco.2022.103836), this toolkit implements a modified approach to local prediction. Instead of relying on a parametric distance gradient, the algorithm uses weighted observations within locally determined catchment areas. Moreover, instead of selecting from a predefined set of radii, the algorithm identifies the smallest possible radius that satisfies a minimum observation threshold. This allows for a more flexible adaptation of the local estimation window to heterogeneous market densities. But it implies less control over the local windows by the user.

We are working on an **interactive webtool** to illustrate the latest edition of the postcode-level price and rent indices for Germany.

Upon publication of the Ahlfeldt, Heblich, Seidel, Yin (2026) paper, we will make the algorithm and a synthetic trial dataset available.

When using the toolkit in your work, please **cite Ahlfeldt, Heblich, Seidel, Yin (2026): The Price of Productivity. Berlin School of Economics Discussion Paper 91**. Please notice that this paper is pre-publication and, as such, the methodology and the indices may evolve.

This toolkit complements and extends the [AHS2023-toolkit](https://github.com/Ahlfeldt/AHS2023-toolkit), which continues to provide residential property price and rent indices based on the original methodology developed by [Ahlfeldt, Heblich, Seidel (2023)](https://doi.org/10.1016/j.regsciurbeco.2022.103836).

## Folders

| Directory | Sub-folder | Description | Additional Information |
|-------------|------|---|---|
| `APPLICATIONS` | `GERMANY` | Folder containing the application of the Ahlfeldt, Heblich, Seidel, Yin (2026) methodology for Germany | This folder contains indices computed based on **real** data |
| `APPLICATIONS` | `GERMANY/DATA` | Folder containing indices generated by Ahlfeldt, Heblich, Seidel, Yin (2026) for Germany | This folder contains indices computed based on **real** data |
| `APPLICATIONS` | `GERMANY/SHAPES` | Folder containing shapefiles for illustration of the indices | - |
| `APPLICATIONS` | `GERMANY/MAPS` | Folder containing maps for illustration of the indices | - |
