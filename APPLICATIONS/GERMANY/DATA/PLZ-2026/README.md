# AHSY-toolkit
Toolkit for micro-geographic property commercial rent indices

**© Gabriel M. Ahlfeldt, Fan Yin**
Version 0.90, 2026

## General remarks 
This toolkit covers the algorithm by [Ahlfeldt, Heblich, Seidel, Yin (2026)](https://github.com/Ahlfeldt/DPs/blob/main/GA_SH_TS_FY_-_Productivity.pdf) to generate micro-geographic commercial rent indices indieces using the RWI-GEO-REDC (v4) dataset.

The 2025 version dataset contain indices between 2007 and 2024 and are available in wide and long formats:

AHS-Index-com-PLZ-2025 contains the index for office rents

AHS-Index-retail-PLZ-2025 contains the index for retail rents. Notice that retail rents are even scarcer than office rents. In some years, the number of observations is too low to compute reliable index values, which is why they are missing. Even for the other years, we recommend that the values are used primarily for descriptive purposes.
