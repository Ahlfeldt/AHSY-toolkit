# Municipality index update — 13 October 2026

The 2026 municipality indices were generated with the Python AHSY implementation maintained in the production toolkit. This release adds residential rents, residential purchase prices, and retail rents and updates office rents through 2025.

All products use 10,997 municipalities under the 2021 municipality definition and apply the 50-observation municipality-year prediction rule. The published GitHub release contains long and wide CSV and Stata DTA files. Production GIS files and maps are retained outside the public data folder.

The preceding `MUNICIPALITY-2025` office release remains available unchanged for reference.
